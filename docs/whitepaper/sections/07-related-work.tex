\chapter{Related Work and Lineage}
\label{sec:related-work}

The literature usually calls a structure whose answers can be checked against a commitment an \emph{authenticated data structure}. This paper uses \emph{integrity-verifiable} for that structural property and reserves authentication for identity, origin, and authority. The vocabulary keeps digest consistency, signatures, and authorization visible as separate steps.

\section{Integrity and Entangled History}

Cryptographic timestamping establishes one-way succession among committed documents~\cite{Haber1991timestamp}. Persistent authenticated dictionaries make earlier versions queryable~\cite{Anagnostopoulos2001persistent}; general authenticated-structure models and generic programming techniques extend the pattern across data structures~\cite{Martel2004general,Miller2014authenticated}. Compact multiproofs reduce repeated Merkle evidence, while tamper-evident logs organize efficient historical queries and controlled deletion~\cite{Ramabaja2020compact,Crosby2009efficient}. Transparency systems apply these structures to public accountability. Certificate Transparency, CONIKS, and CHAINIAC use append-only or collectively witnessed histories to make authority behavior inspectable~\cite{Laurie2014certificate,Melara2015coniks,Nikitin2017chainiac}. PeerReview combines attributable logs with deterministic replay for distributed systems, and transparency overlays generalize witness comparison across applications~\cite{Haeberlen2007peerreview,Chase2016transparency}. Maniatis and Baker's secure timeline entanglement is the direct precedent for bridge-composed history~\cite{Maniatis2002timeline}. Timeweave imports signed foreign timeline threads into later authenticators, yielding temporal mappings, incorporation receipts, and proofs that survive the originating service. Synchronic Web bridges carry this established mechanism into sparse relationships among journals whose histories contain path-addressed, partially retained, self-encoding state.

\section{Provenance and Preservation}

Untrusted-storage systems show how clients can retain compact state and detect server equivocation or tampering~\cite{Li2004secure,Mahajan2010depot,Kim2015caelus}. The Synchronic Web adopts the same client-held-commitment discipline while allowing each journal to maintain its own state and history. Database provenance distinguishes why- and where-provenance, while Web provenance models processes, evidence, and responsibility~\cite{Buneman2001why,Moreau2010foundations,Moreau2010open}. W3C PROV standardizes entities, activities, agents, derivations, and responsibility for interoperable exchange~\cite{Moreau2013prov}. Nanopublications package scientific assertions with provenance and publication context~\cite{Groth2010anatomy}; secure provenance protects provenance records as they cross untrusted environments~\cite{Hasan2009provenance}. These models can inhabit journal resources as application vocabularies. Content-derived naming and distributed preservation supply another lineage. IPFS, Trusty URIs, secure names, and self-certifying paths bind identifiers to content or cryptographic authority~\cite{Benet2014ipfs,Kuhn2014trusty,Haber1997secure,Mazieres1998path}. Merkle-CRDTs use Merkle DAGs for convergent replication, Named Data Networking centers retrieval on named data, and LOCKSS combines peer replication with auditing for preservation~\cite{Sanjuan2020merkle,Zhang2014named,Maniatis2005lockss}. Tiered fault tolerance treats rare failures and cryptographic aging as ordinary long-horizon events~\cite{Chun2009tiered}. The Synchronic Web joins these concerns through resources whose content, history, and interpretation can be retained at different levels of completeness.

\section{Decentralized Webs and Identity}

Web architecture separates resource identification, representations, and interaction; RFC~3986 supplies global URI syntax and relative-reference resolution~\cite{Jacobs2004webarch,BernersLee2005uri}. Memento adds datetime negotiation and TimeMaps for earlier resource states~\cite{VanDeSompel2013memento}. Synchronic Web paths apply rooted and historical resolution within a journal's verifiable state. SDSI develops linked local namespaces, and SPKI/SDSI chain discovery builds proofs of naming and delegated authority for a relying party's policy~\cite{Rivest1996sdsi,Clarke2001chain}. Decentralized trust management likewise evaluates presented credentials under local rules~\cite{Blaze1996trust}. Historic name trails follow changing online identifiers~\cite{Maniatis2003hints}, while earlier Synchronic Web identity work describes verifiable chains between anchors~\cite{dinh2025identity}. Receiver-relative principals and exact committed-object routes give these ideas a construction from checkpoints retained in journal history. Local-first software emphasizes local ownership and responsive operation; Solid separates user-controlled stores from applications~\cite{Kleppmann2019local,Mansour2016solid}. Webstrates persists and synchronizes mutable DOM state, including code, while AT Protocol combines signed per-user repositories, decentralized providers, and account portability~\cite{Klokmose2015webstrates,Kleppmann2024bluesky}. Data spaces develop governance among organizations, and the Semantic Web pursues machine-interpretable relationships among resources~\cite{Otto2019designing,BernersLee2001semantic}. Verifiable credentials provide a mature vocabulary for issuer, holder, verifier, claim, and proof roles~\cite{Sedlmeir2021digital}. The journal-relative Web places these application and governance choices above a common layer of integrity, history, and local policy.

\section{Persistent Computation and Agents}

Orthogonal persistence makes values durable independent of type-specific storage code, while tierless languages reduce representational boundaries across application layers~\cite{Atkinson1983approach,Cooper2007links}; Emerald supports mobile objects, Argus structures distributed programs through guardians and atomic actions, Safe Tcl confines portable scripts, and proof-carrying code attaches statically checkable evidence to behavior~\cite{Raj1991emerald,Liskov1988distributed,Levy1995safe,Necula1997proof}. Distributed computation offers neighboring models: Ethereum and Hyperledger Fabric couple execution to shared ledger governance~\cite{Wood2014ethereum,Androulaki2018hyperledger}, Linda provides associative tuple spaces~\cite{Gelernter1985generative}, Bayou supports weak connectivity, Dynamo prioritizes availability, and CRDTs define convergent replicated types~\cite{Terry1995managing,DeCandia2007dynamo,Shapiro2011conflict}. CALM characterizes monotonic programs that avoid coordination, while Merkle search trees organize state-based CRDT exchange~\cite{Hellerstein2020keeping,Auvolat2019merkle}. Self-encoding objects draw from these traditions by binding behavior and state inside an integrity-protected representation evaluated locally while histories preserve relationships among independently advancing states. Agent systems illustrate the demand for durable structured context. Retrieval-augmented generation supplies external documents; Generative Agents stores experience streams and reflections; AriGraph combines semantic and episodic memory; and HippoRAG builds a long-term retrieval index~\cite{Lewis2020retrieval,Park2023generative,Anokhin2025arigraph,Gu2024hipporag}. Agent-oriented programming and KQML provide an earlier lineage for explicit state, intention, and communication~\cite{Shoham1993agent,Finin1994kqml}. Journals offer these systems portable evidence, historical correction, and locally evaluated reputation while leaving agent orchestration to the application. Every major ingredient therefore has a substantial precedent. The architectural contribution is their composition: self-encoding structures retain identity under partial possession, independent histories become entangled, journal-relative paths expose those histories as resources, and clients turn proof handling into ordinary interaction. Composable-ledger work provides an earlier step toward this synthesis~\cite{dinh2023composable}; the present architecture develops it into a plural Web.
